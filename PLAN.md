# Alibi implementation plan

1. Define a deterministic, server-owned state machine and private player projections.
2. Build a same-origin Node/Express + Socket.IO server with HttpOnly random sessions.
3. Build the complete responsive interface and original interrogation-room identity.
4. Cover rules and authorization with Node tests, real socket integration checks, and independent browser contexts.
5. Document recovery/deployment, record verified results, and leave a local server running.

## State specification / implementation contract

The engine exports `GameStore` from `server/game.js`, and `CATEGORIES`, `WORDS` from `server/words.js`.
`new GameStore({ now = Date.now, randomInt, graceMs = 60000 } = {})` owns rooms. Methods: `create(playerId, {nickname, avatar})`, `join(playerId, {code,nickname,avatar})`, `act(playerId, {type, actionId, roundId, turnId, ...payload})`, `connect(playerId)`, `disconnect(playerId)`, `sweep()`, `view(playerId)`, `roomFor(playerId)`. Mutations return any value; transport always broadcasts fresh personalized `view` snapshots. Invalid actions throw an Error with a user-safe message. A session can belong to one room; explicit leave is required before switching.

Public snapshot: `{code, hostId, phase, roundNumber, roundId, revision, categories: [id], players:[{id,nickname,avatar,connected,waiting,ready,departed,disconnectDeadline}], me:{id,isHost,role?,word?,category?,ready,hasVoted,eligible}, turn:{id,currentId,nextId,finishedIds,order,lap,paused}|null, voting:{submitted,total,candidateIds,runoff,deadline}|null, accusedId?, result?, notice?}`. Role is `insider` or `imposter`. Round results contain `{winner:'group'|'imposter'|null,reason,word,imposterId,guess?,ballots:[{runoff,votes:[{voterId,targetId}]}]}`. Abandoned rounds use `phase: 'results'`, null winner and a clear reason. No private info in public fields before results; late joiners receive no role/word/category. Each view is newly projected, never a spread of internal round state.

Actions: `categories` with `categories`; `start`; `ready`; `done`; `pause`; `advance`; `extra-lap`; `vote-start`; `vote` with `targetId`; `guess` with `guess`; `leave`. Every action requires a unique actionId and matching room `code`; every round action (including start/categories, lobby roundId=0) requires matching roundId; done/advance/pause require matching turnId. Votes require matching `votingId` against `voting.id` so an initial-ballot action cannot spill into a runoff. The latest 512 successful actionIds per player are idempotent for up to 24 hours. Phase validation also prevents start/ready/vote/guess duplicates. Start is allowed in lobby/results only, 4–10 connected players, at least one category. A new start increments roundId and selects an unused word from selected categories (reset only once that selected pool is exhausted).

Final projection additions: top-level `lap` remains visible during discussion, `phaseDeadline` supports readiness/final-guess countdowns, and `ballots` exposes only completed ballots. `turn` exists only during clues; `voting` exists only during voting/runoff.

Phases: lobby → reveal → clues → discussion → voting → [runoff] → [guess] → results. Exactly one independently randomized imposter; independently shuffled speaking order. All participants ready before clues. One optional extra lap per round. Private voting excludes self, reveals complete ballots only after each ballot closes. Tied leaders cause one runoff, second tie awards imposter win. Caught imposter has one normalized guess; correct guess wins. Normalize case, spacing and punctuation, checking curated aliases.

Interruption policy: disconnected members get 60 seconds to reclaim their cookie-bound seat. Host transfers immediately to the earliest connected room member; does not transfer back automatically. Explicit leave expires immediately. An active round is abandoned when any participant's grace expires or they explicitly leave: this avoids changing the electorate, silent abstentions, missing guesses, and unfair role-dependent disconnect outcomes. During grace the host may advance stalled clue turns. Voting has a 90-second deadline; an incomplete ballot abandons the round without inventing votes. Guess has a 60-second deadline; no guess forfeits to the group, except a disconnected imposter's expired grace abandons first. Reveal has a 120-second deadline; incomplete readiness abandons the round. Late arrivals wait until next round. Expired seats leave the room; round roster is preserved until results. Empty rooms expire after 30 minutes, sessions after 24 hours; in-memory state is lost on server restart.

## Transport

POST `/api/session` creates/refreshes an opaque 256-bit HttpOnly, SameSite=Lax cookie (Secure with HTTPS production configuration), returns `{playerId}`. Socket authentication is cookie-only; never accept client player IDs. `room:create`/`room:join` accept nickname/avatar/code and ack `{ok,error?}`; `action` accepts engine action object with same ack. `state` is always a personalized snapshot or null. `catalog` is public category metadata only. Same-origin API/socket origin validation, request size limits, basic action/request rate limits, no word collection served statically. Multiple tabs share a seat; connected status only drops after its last socket closes.
